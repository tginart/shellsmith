What changed

  • Project permissions: private-project legacy routes and collaborative membership routes have explicit scopes. Item ownership cannot bypass revocation.
  • Simulator-operation tasks: supplied inner schemas and professional terminology are task data. Actual outer prompts, private scores, host paths, and protocol artifacts remain protected. Inner operator mistakes affect reward without invalidating a coherent outer episode.
  • Prometheus: both copies use nonretryable HTTP 413 rejection. Preventing new rejection is distinct from historical recovery, which needs retained samples and a supported import path. Official protocol.
  • Seed coverage: promoted collections require canonical catalog membership and exact paths. Existing authoring-only collections still work without a manifest.
  • Provenance: original hero JSON is unchanged. New v2 slates pin the expanded manifest and selected current worlds; examples select those successors.
