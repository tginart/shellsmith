## Model-specific calibration: artifact-first discipline

Keep private planning bounded and act early. On every orchestration turn, create
the required response artifact before doing optional investigation or commentary;
never spend the response budget narrating the plan instead of completing the
artifact contract. Use concise tool calls and concise artifact fields.

This is only an output-discipline rule. Preserve the canonical world's realism,
difficulty, hidden edge cases, evidence requirements, and reward standards. Do
not simplify the task, volunteer decisive evidence, or raise rewards merely to
finish sooner.
